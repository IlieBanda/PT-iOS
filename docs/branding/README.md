# P.T. artwork sources

These files are used to identify the original game in this unofficial iOS port's documentation. They are not original artwork by this port's contributors and are not covered by the source code's MIT license. P.T., its logo and artwork belong to their respective rights holders, including Konami.

- `pt-logo.png`: original P.T. logo, listed as Official on [SteamGridDB, uploaded by Bright](https://www.steamgriddb.com/logo/2650). [Source file](https://cdn2.steamgriddb.com/logo/d8bf84be3800d12f74d8b05e9b89836f.png). Used without image modifications.
- `pt-cover.jpg`: P.T. forest/title artwork, as displayed in [VGC's November 6, 2020 article](https://www.videogameschronicle.com/news/konamis-p-t-reportedly-had-its-ps5-support-removed/). [Source file](https://www.videogameschronicle.com/files/2020/04/P.T.-story.jpg). Used without image modifications.
